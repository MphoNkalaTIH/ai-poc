MASTER END-TO-END HARDWARE INTEGRATION GUIDE: NUMINA HIGH SCHOOL ROBOT
===============================================================================
Target System: Raspberry Pi 5 (2GB) with Monitor Swap & 100nF Audio Modification
Document Version: 2.0 (Complete Comprehensive Hardware Layout)

This file contains the absolute end-to-end master hardware schematic map for the
Numina teaching robot. Every component from the input switches, status indicator 
LED arrays, custom audio path adapters, to the SPI-driven MAX7219 LED Matrix is 
laid out step-by-step with explicit pin-to-pin definitions.

-------------------------------------------------------------------------------
SECTION 1: ISOLATED POWER DISTRIBUTION  [done]
-------------------------------------------------------------------------------
The PAM8403 Amplifier experiences high peak currents (up to 3A). To avoid logic
voltage brownouts or damage to the Raspberry Pi 5, the power lines are completely
isolated onto parallel distribution rails.

A. Power Source Inbound:
   1. Connect Main 27W Power Delivery Adapter Output V+ (5V, 5A) to Power
      Distribution Board Rail A (+).
   2. Connect Main 27W Power Delivery Adapter Output V- (GND) to Power
      Distribution Board Rail B (-).

B. Logic Branch (Raspberry Pi 5):
   1. Route a thick line from Distribution Rail A (+) to RPi 5 Physical Pin 2 (+5V).
   2. Route a thick line from Distribution Rail B (-) to RPi 5 Physical Pin 6 (GND).

C. Audio Branch (PAM8403 Amplifier):
   1. Route a thick line from Distribution Rail A (+) to the PAM8403 Power "+" terminal.
   2. Route a thick line from Distribution Rail B (-) to the PAM8403 Power "-" terminal.
   3. Capacitor Filtering: Mount your 100uF 25V Electrolytic Filtering Capacitor
      directly across the PAM8403 Power "+" and Power "-" terminals.
      *CRITICAL ASPECT*: Ensure the capacitor's negative lead (indicated by the 
      silver/white stripe on the body) is aligned perfectly with the Power "-" pin.

-------------------------------------------------------------------------------
SECTION 2: 6-BUTTON CONTROL INTERFACE MATRIX MAP (INTERNAL PULL-UP STATE) [done]
-------------------------------------------------------------------------------
To bypass structural breadboard crowding, all six interaction momentary buttons 
are wired directly between their specific Raspberry Pi 5 GPIO sensing pin and a
common shared Ground (GND) rail. Software will initialize internal pull-up profiles.

- BUTTON 1: START SWITCH
  * Button Terminal 1 -> Raspberry Pi 5 Physical Pin 13 (GPIO 27)
  * Button Terminal 2 -> Shared Ground Rail (e.g., Physical Pin 9 / Common GND)

- BUTTON 2: EMERGENCY STOP SWITCH
  * Button Terminal 1 -> Raspberry Pi 5 Physical Pin 15 (GPIO 22)
  * Button Terminal 2 -> Shared Ground Rail

- BUTTON 3: NAVIGATION UP SWITCH
  * Button Terminal 1 -> Raspberry Pi 5 Physical Pin 16 (GPIO 23)
  * Button Terminal 2 -> Shared Ground Rail

- BUTTON 4: NAVIGATION DOWN SWITCH
  * Button Terminal 1 -> Raspberry Pi 5 Physical Pin 18 (GPIO 24)
  * Button Terminal 2 -> Shared Ground Rail

- BUTTON 5: NAVIGATION LEFT SWITCH
  * Button Terminal 1 -> Raspberry Pi 5 Physical Pin 22 (GPIO 25)
  * Button Terminal 2 -> Shared Ground Rail

- BUTTON 6: NAVIGATION RIGHT SWITCH
  * Button Terminal 1 -> Raspberry Pi 5 Physical Pin 37 (GPIO 26)
  * Button Terminal 2 -> Shared Ground Rail

-------------------------------------------------------------------------------
SECTION 3: AUDIO INTERFACE: PICO H ADC USB MICROPHONE BRIDGE & SAFE OUTPUT
-------------------------------------------------------------------------------
Since the Waveshare sound card lacks a hardware mic input port, analog voice capture
is handled securely by programming the alternative Raspberry Pi Pico H to act as a 
USB Audio Class ADC converter device, filtering audio directly into the Pi 5 USB.

A. Preamp & Pico H ADC Audio Input Execution (Breadboard Rows 30-45, Cols F-J):
   1. Connect Pico Pin 36 (3V3_OUT) -> Breadboard +3.3V Power Rail.
   2. Connect Pico Pin 38 (GND) -> Breadboard Common GND Rail.
   3. Route Logitech Mic White Wire (+) -> Leg A of 100nF Ceramic Capacitor.
   4. Route Leg B of 100nF Ceramic Capacitor -> 2N2222 Transistor Base (Center Pin).
   5. Route Logitech Mic Bare Wire (-) -> Breadboard Common GND Rail.
   6. Wire a 100kΩ Resistor from the +3.3V Rail to the Transistor Base pin.
   7. Wire a 10kΩ Resistor from the Transistor Base pin to the GND Rail.
   8. Connect the 2N2222 Transistor Emitter (Right Pin) directly to the GND Rail.
   9. Connect a 1kΩ Load Resistor from the +3.3V Rail to the Transistor Collector (Left Pin).
   10. Run a jumper wire from the Transistor Collector (Left Pin) -> Pico H Pin 31 (ADC0 / GP26).
   11. Use a standard Micro-USB cable to connect the Pico H directly to a RPi 5 USB port.

B. Waveshare Sound Card Outputs to PAM8403 Amp Single-Ended Safe Audio Bridge:
   1. Connect Sound Card VOLP (Left +) pin -> Leg A of a third 100nF Ceramic Capacitor.
   2. Connect Leg B of that 100nF Ceramic Capacitor -> PAM8403 "L" (Left Input) pin.
   3. Connect Sound Card VOLN (Left -) pin -> Direct wire to PAM8403 "G" (Audio Ground Input) pin.
   4. DO NOT CONNECT VORP or VORN anywhere. Leave these pins completely open to eliminate loops.

C. Amplifier Outputs to Logitech Mono Speaker:
   1. Connect the Logitech Speaker Positive (+) wire to PAM8403 "Lout+" terminal.
   2. Connect the Logitech Speaker Negative (-) wire to PAM8403 "Lout-" terminal.
   3. Leave the Rout+ and Rout- terminals completely unpopulated.


-------------------------------------------------------------------------------
SECTION 5: MAX7219 8x8 LED MATRIX DISPLAY BUS ARRAY
-------------------------------------------------------------------------------
The 8x8 LED Dot-Matrix display utilizes the high-speed hardware SPI bus channels
on the Raspberry Pi 5 to draw interactive facial expressions and characters.

1. MAX7219 VCC Pin  -> Raspberry Pi 5 Physical Pin 4 (+5V Core Logic Power)
2. MAX7219 GND Pin  -> Raspberry Pi 5 Physical Pin 9 (GND)
3. MAX7219 DIN Pin  -> Raspberry Pi 5 Physical Pin 19 (GPIO 10 / Hardware SPI_MOSI)
4. MAX7219 CS Pin   -> Raspberry Pi 5 Physical Pin 24 (GPIO 8 / Hardware SPI_CE0)
5. MAX7219 CLK Pin  -> Raspberry Pi 5 Physical Pin 23 (GPIO 11 / Hardware SPI_SCLK)
